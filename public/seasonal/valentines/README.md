# Valentine's Seasonal Page Assets

This directory contains assets for the Valentine's seasonal page.

## Required Assets (to be added by content team):

### Hero Section
- **hero.mp4** - Full-viewport background video (MP4 format)
  - Recommended: 1920x1080 or higher
  - Keep file size under 5MB for performance
  - Should be muted, suitable for looping
  
- **hero-poster.jpg** - Poster/fallback image for video
  - Same dimensions as video
  - Will be shown while video loads

### Product Picks
Place 4-8 product images in `/picks/` directory:
- Format: JPG or WebP
- Recommended size: 600x600px
- Naming: pick-1.jpg, pick-2.jpg, etc.

### Video Loops
Place short video loops in `/loops/` directory:
- Format: MP4
- Keep under 2MB each
- Example: texture-drip.mp4

## Current Status
Placeholders are in place. The page will function with placeholders until real assets are added.
